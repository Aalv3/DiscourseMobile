# Wave 3.2 Premium Native Pass

This pass refines composition and hierarchy without changing functionality,
navigation, authentication, permissions, data contracts, native dependencies,
or OTA runtime.

## Applied changes

- Rebalanced light and dark palettes around warm neutral canvases, AN navy, and
  restrained AN red identity accents.
- Tightened typography, radii, spacing, filters, and interaction states.
- Integrated the AN mark and brand rule into a more compact global shell.
- Recast Floor as a briefing with one featured item, numeric network pulse,
  intelligence desk, and lower-weight discussion feed.
- Recast Discussions as a people-forward editorial feed using avatars,
  category/author/activity hierarchy, compact filters, and dividers.
- Strengthened topic authorship, starter identity, thread context, and compact
  icon-supported contribution actions.
- Preserved Lounge's chat model while tightening message rhythm and composer depth.
- Made Ask's privacy guidance an intentional trust panel rather than a generic card.
- Added numbered desk hierarchy to Intelligence and editorial empty collection states.
- Separated the You screen's professional identity from member tools.
- Unified Search, Bookmarks, Settings, Account, Notifications, Appearance,
  Privacy, and profile editing with the member-workspace visual language.

## Evidence

The `before/` and `after/` directories contain matched Simulator-native captures
at consistent iPhone 17 Pro dimensions. They include the nine requested surfaces,
a representative dark mode, and an accessibility-large state.

Subjective approval remains with the owner; this package records implementation
and evidence only.
