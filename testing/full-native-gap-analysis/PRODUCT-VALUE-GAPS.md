# Product value gaps

| Destination | Purpose | Useful action | Return value | Build 1 verdict |
|---|---|---|---|---|
| Floor | Daily member briefing and recent conversation entry | Opens recent topics; Search and Notifications | Weak while all intelligence panels are static | Functional, but P1 data integration needed |
| Discussions | Durable professional knowledge and conversation | Filter, open, reply, creator-delete | Strong when content exists | Functional; Edit and complete category discovery remain gaps |
| Lounge | Open member chat | Read, send, emoji, delete own message | Good with active members; 10-second updates | Earns primary placement; realtime/reactions are P2 |
| Ask | Guided safe question creation | Category, compose, submit, native topic | Clear member value | Functional; current mutation not re-run in this audit |
| Intelligence | Three authenticated native collections | Open collection/topic | Low if all three remain empty or duplicate tag-list shells | Functional but P1 content/value gap |
| You | Member identity and utilities | Profile, settings, bookmarks, search, logout | Useful hub | Functional; profile depth and Adjuster Card are shared/backend blocked |

## Highest-value parity gaps

1. Adjuster Card identity/profile foundation is absent from native and disabled/incomplete on the
   shared backend.
2. Own-post editing is absent despite Discourse capability support.
3. Floor does not consume the Intelligence data it visually promises.
4. Native notification settings are substantially narrower than web preferences.
5. Search copy exceeds capability because member results are not shown.
6. Bookmarks are list-only; topics cannot be bookmarked or unbookmarked natively.
